How to move from YNAB to Actual Budget, and keep your targets

Actual Budget is a free, open-source budgeting app that runs on your own server, and it already works the way YNAB people think: envelopes, money waiting to be budgeted, categories that roll over. Moving is mostly one import. This guide covers the free way, the one big thing it leaves behind, and how to bring that across too.

I'm David Alves, and I make Bridge Budget, one of the two ways described here. The free way comes first, because for many people it's all they need.

The short answer

  • You don't use YNAB targets, or you're happy to set them again: use Actual's own YNAB import. It's free.
  • You rely on your targets: Actual's import leaves them behind. Bridge Budget brings them across with everything else, from a token instead of an export file.

Before you start

  • Somewhere to run it. Anything that runs Docker: a NAS, a home server, a Mac or Windows PC, or a Raspberry Pi 4 or 5 with a 64-bit system. Actual's install guide lists every option.
  • Your YNAB login. Neither import changes anything in YNAB, so you can run both side by side until you're sure.
  • About half an hour. Most of it is installing. The import itself takes a minute or two.

The free way: Actual's own import

  1. Install Actual

    Follow Actual's install guide. With Docker it's one small compose file using the actualbudget/actual-server image. Open it in your browser, set a server password, and you're in.

  2. Export your YNAB budget as a JSON file

    YNAB has no export button for a whole budget, so Actual's migration page lists several ways to get the file: a community web tool, YNAB's own API documentation page in your browser, a small command-line tool, or curl. All but the web tool need a YNAB personal access token: in YNAB open Developer settings, click New Token, type your password and copy the token. YNAB shows it only once.

  3. Import it

    In Actual, open the menu at the top left, choose Switch file, then Import file, then nYNAB, and pick the JSON file.

Going by Actual's import code, this brings across your accounts (closed and tracking accounts included), every transaction with its payee and memo, your categories and groups with their notes, what you assigned each month, your scheduled transactions as Schedules, and your flags as tags.

What stays behind

  • Targets. Actual's importer doesn't read YNAB's target settings, so every category arrives without one. In Actual itself, targets are written as #template lines in each category's notes, a feature its docs still mark as experimental. If you had a lot of targets, this is the part that takes an evening.
  • Credit Card Payment categories. Actual handles credit card spending differently and doesn't create those categories, so money that sat in them can show up as money to budget. Actual's migration page explains how to tidy it.
  • Bank connections. YNAB's linked accounts belong to YNAB's bank partners and don't move with any import. More on that below.

Keeping your targets: Bridge Budget

Bridge Budget is built on Actual's open-source engine. It uses the same YNAB import as Actual, with two additions: it reads your targets, and it fetches your budget straight from YNAB with a token, so there's no file to export first. It also adds the YNAB-style budget screen to use them: targets you set with a few clicks, one-click funding of everything underfunded, and five reports.

  1. Install it

    Already running Actual? Change one line in your docker-compose.yml and restart. Your data folder stays as it is.

    image: daalves/bridge-budget:latest
    docker compose pull && docker compose up -d

    Starting fresh, the setup guide has the three commands.

  2. Make a YNAB token

    In YNAB's Developer settings, click New Token, type your YNAB password, click Generate and copy the token shown at the top.

  3. Paste it and pick your budget

    In Bridge Budget choose Import my budget on the welcome screen (or Import file in your list of budgets), then YNAB, paste the token and pick the budget. Everything above comes across, targets included, in about a minute. The token is used once, from your browser straight to YNAB, and never saved. You can delete it in YNAB afterward.

After the move, either way

  • Bring your bank back in. In Europe, Bridge Bank syncs 2,500+ banks into Actual or Bridge Budget automatically, read-only, on your own server. Anywhere else you can import your bank's file (CSV, OFX or QIF), or see what Actual's own bank sync offers in your country.
  • Check this month's total. Actual and YNAB count money set aside for future months a little differently, so the amount left to budget may not match at first. Actual's migration page explains how "Hold for next month" lines them up.
  • On your phone, it runs in the browser and can sit on your home screen. There's no app store app.
  • Keep YNAB until you're sure. Nothing is changed there, so the simplest plan is to run both for a few weeks and cancel YNAB before it renews.

Questions

Is Actual Budget really free?
Yes. It's open source and you run it yourself, so there's no subscription. Your only cost is whatever you run it on.
Will importing change anything in my YNAB account?
No. Both ways only read your budget. Delete the token in YNAB's Developer settings when you're done if you like.
Can I go back from Bridge Budget to plain Actual?
Yes. Underneath it's a standard Actual budget. Put the Actual image back in your compose file and run the same update command; your budget opens as it is, without the Bridge Budget screens.
Does it work outside Europe, or in other currencies?
Yes, both do. Only Bridge Bank's automatic sync is for European banks.
I already imported into Actual. Can I add my targets later?
You can set them by hand in Bridge Budget with a few clicks per category. To bring them across from YNAB automatically, import again from YNAB into a new budget file.
